PROJECT DEEP DIVE

Elastic SIEM Deployment & Windows Log Centralization

SECURITY MONITORING & LOG ANALYSIS

Engineered a centralized Security Information and Event Management (SIEM) architecture using the Elastic Stack and Filebeat to ingest, parse, and analyze Windows event logs in real time. Designed custom Kibana dashboards to support threat detection, event correlation, and incident investigation workflows.

Core Architecture & Pipeline Configuration

  • Log Ingestion Pipeline: Configured Filebeat on Windows target endpoints to harvest critical event logs (Security, System, and Application channels) and securely forward them to Elasticsearch.
  • Data Parsing & Indexing: Structured incoming raw telemetry into standardized indices, mapping timestamps, source IPs, and user contexts to optimize search queries and event filtering.
  • Elasticsearch Backend: Deployed and managed the core database cluster to handle storage scaling, index lifecycle management, and efficient log searching.

Dashboard Visualization & Monitoring

Built custom Kibana data visualizations and operational dashboards tailored for Security Operations Center (SOC) visibility:

  • Authentication Tracking: Visualized successful vs. failed logon attempts over time to spot brute-force attacks and abnormal login spikes.
  • Account Activity Monitors: Tracked account creation, group modifications, and privilege elevation events across the domain.
  • System Event Aggregation: Displayed service state changes, application faults, and security policy modifications in a centralized view.

Threat Investigation & Use Cases

Investigated simulated security incidents and suspicious operating system behaviors by querying specific Windows Event IDs:

  • Event ID 4625 (Failed Logon): Tracked repetitive authentication failures indicating password-guessing attempts.
  • Event ID 4720 (User Account Creation): Monitored for unauthorized persistence mechanisms or rogue account creation.
  • Event ID 4672 (Special Privileges Assigned): Investigated high-privilege token assignments associated with administrative access.

Technologies & Tools

Tools: Elastic Stack (Elasticsearch, Kibana), Filebeat, Windows Server, Windows Event Logs

Skills: Log Collection, SIEM Monitoring, Event Analysis, Dashboard Design, Incident Documentation
