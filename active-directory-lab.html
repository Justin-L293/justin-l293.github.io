PROJECT DEEP DIVE

Windows Active Directory Lab & Identity Management

IDENTITY & ACCESS MANAGEMENT / SYSTEMS ADMINISTRATION

Configured and administered enterprise-grade Windows Active Directory Domain Services (AD DS) environments hosted within VMware virtualized lab architecture. Designed hierarchical directory structures, managed identity lifecycles, and implemented security hardening policies.

Domain Controller Deployment & Setup

  • AD DS Installation: Promoted Windows Server instances to Domain Controllers (DCs), configuring DNS, DHCP, and global catalog services within the forest.
  • Virtualization Management: Leveraged VMware snapshots and virtual switches to maintain isolated domain networking and safe testing boundaries.

Identity Lifecycle & Group Management

Structured directory components to reflect real-world enterprise administrative workflows:

  • Organizational Unit (OU) Design: Created structured OU hierarchies mirroring departmental layouts to delegate administrative control and apply targeted configurations.
  • User Account Provisioning: Managed user creation, password policies, account lockouts, and credential management standards.
  • Security & Distribution Groups: Implemented role-based access control (RBAC) by organizing security groups and managing group memberships.

Windows Administration & Security Configuration

Applied administrative hardening and policy controls across the domain:

  • Group Policy Objects (GPOs): Configured and linked GPOs to enforce desktop settings, security baselines, and restriction policies across domain-joined systems.
  • Domain Joining: Integrated Windows client workstations into the domain, validating secure authentication channels and replication health.

Technologies & Tools

Tools: Windows Server, Active Directory Domain Services (AD DS), VMware, Group Policy Management

Skills: Account Administration, Group Management, Organizational Unit Architecture, Windows Administration, Identity & Access Management
