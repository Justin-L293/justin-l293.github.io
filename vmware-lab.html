PROJECT DEEP DIVE

Virtual IT Lab Environment

SYSTEMS ADMINISTRATION & INFRASTRUCTURE

This project involved the design, deployment, and ongoing administration of a localized enterprise lab environment. Built inside VMware, the lab simulates multi-tiered production networks to practice core systems administration, user lifecycle management, and troubleshooting tasks.

Key Architecture & Responsibilities

  • Multi-OS Deployment: Provisioned and maintained 6 to 10 virtual machines running Windows 10, Windows Server, and multiple Linux distributions.
  • Active Directory Implementation: Configured domain services, managed user accounts, enforced group policies, and organized security groups and OUs.
  • Network Diagnostics: Used tools like Wireshark and Nmap to map out network segments, capture traffic, and verify connectivity across virtual subnets.
  • Routine Maintenance: Handled software patching, updates, system recovery configurations, and detailed technical documentation.

Technologies & Tools Utilized

Tools: VMware ESXi/Workstation, Windows Server, Windows 10, Linux, Active Directory, Wireshark, Nmap

Skills: Virtualization, Systems Administration, Troubleshooting, Network Configuration, Access Control
