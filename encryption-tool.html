PROJECT DEEP DIVE

Bash File Encryption Tool

LINUX & SCRIPTING SECURITY

Engineered a robust command-line file encryption and decryption utility written in Bash and powered by OpenSSL. The tool provides strong local data protection using the industry-standard Advanced Encryption Standard with Cipher Block Chaining (AES-256-CBC).

Key Architecture & Implementation

  • AES-256-CBC Encryption: Utilizes a 256-bit key with salt generation to secure both text and binary files against pattern and brute-force attacks.
  • Automated Key Management: Automatically generates cryptographically secure keys via OpenSSL's pseudorandom number generator when a custom key is not provided.
  • Secure Key Storage: Stores generated keys locally in a dedicated file (`encryption_key.txt`) protected by restricted user permissions (`chmod 600`) to prevent unauthorized access.
  • File Integrity Verification: Computes and stores SHA-256 file hashes (`.hash`) prior to encryption, verifying post-decryption integrity to ensure files have not been modified or corrupted.
  • Rigorous Error Handling: Validates file paths, readability, output directory write permissions, and operation flags with informative error messaging and a built-in help menu (`-h`).
