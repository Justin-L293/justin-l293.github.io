PROJECT DEEP DIVE

AWS Cloud Infrastructure Lab & Infrastructure as Code

CLOUD INFRASTRUCTURE & DEVOPS

Provisioned, managed, and automated cloud environments on Amazon Web Services (AWS) using CloudFormation templates. Designed repeatable Infrastructure as Code (IaC) architectures incorporating secure networking topologies, EC2 compute resources, and granular security group isolation.

Infrastructure as Code (IaC) with CloudFormation

  • Template Authoring: Developed declarative JSON/YAML CloudFormation templates to standardize infrastructure deployment and eliminate manual configuration drift.
  • Stack Lifecycle Management: Managed stack creation, updates, and rollbacks safely across test environments, ensuring atomic infrastructure changes.

Cloud Networking & Compute Configuration

Engineered secure virtual networking components to support isolated cloud workloads:

  • VPC Architecture: Configured Virtual Private Clouds (VPCs) featuring public and private subnets, internet gateways, and route tables.
  • EC2 Instance Provisioning: Deployed Amazon EC2 virtual servers with optimized AMI selections, instance types, and automated bootstrap scripts.
  • Security Group Hardening: Implemented stateful firewall rules at the instance level, restricting inbound and outbound traffic to least-privilege ports and protocols.

Deployment & Connectivity Troubleshooting

Diagnosed and resolved common cloud deployment bottlenecks:

  • Stack Event Analysis: Inspected CloudFormation event logs to trace dependency errors, resource creation failures, and permission rollbacks.
  • Connectivity Debugging: Resolved routing and network reachability issues by verifying subnet NACLs, security group rule matrices, and route table associations.

Technologies & Tools

Tools: AWS (Amazon Web Services), CloudFormation, Amazon EC2, VPC, Security Groups

Skills: Cloud Infrastructure, Infrastructure as Code (IaC), Cloud Networking, Deployment Automation, Troubleshooting
